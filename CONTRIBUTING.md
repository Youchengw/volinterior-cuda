# Contributing

Please open an issue before a substantial change. Every change should include
tests or a reproducible validation case when it affects numerical behavior.

Pull requests should state:

- the scientific definition and parameters affected;
- whether VMD compatibility was rechecked;
- the CPU/GPU and CUDA versions used for benchmark claims;
- any changes to output schema or provenance metadata.

Do not add private trajectories, production outputs, credentials, or generated
GPU caches to the repository.
